# VOID STRIKE

A fast, neon browser arcade shooter prototype.

## Controls

- Mouse: aim
- Left click: fire
- Spacebar: Nova Blast

## Prototype goals

- One-screen arcade survival loop
- Visually intense particles, glow, screen shake, and combo feedback
- Lightweight browser delivery with no install
- Easy to expand with bosses, weapons, leaderboards, mobile controls, and monetization later

Open `index.html` in a browser to play locally.
